Integration Guide
How to point your bot at this gateway
1. Replace API URL in youtube.py
# OLD — direct Shruti API
PRIMARY_API_URL = "https://api.shrutibots.site"

# NEW — point to this gateway
PRIMARY_API_URL = "http://localhost:8000/proxy"

# Remove the api_key param from your code — gateway injects it automatically
2. Admin API Reference
GET /admin/stats — gateway stats
GET /admin/keys — list all keys
POST /admin/keys — add single key
POST /admin/keys/bulk — bulk add
DEL /admin/keys/:id — delete key
POST /admin/keys/:id/reset — reset key count
POST /admin/keys/reset-all — reset all
GET /admin/logs — request log
GET /admin/health — liveness
ANY /proxy/{path} — proxied upstream
3. Run the Gateway
pip install fastapi uvicorn aiohttp
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
